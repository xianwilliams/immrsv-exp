# IMMRSV

A Next.js website for Nick Wirsching's experiential production collective. The interface uses black and white with small warm-red brand accents; authentic project photography supplies the main color. A clean SVG logo opens into a continuous photo carousel. GSAP and Three.js drive the scroll ribbon, which settles into clickable project cards. Services use a split layout, local IBM Plex Mono labels and icons, full-panel photos, and a six-second autoplay accordion with an orange-red progress line; project popups use autoplay accordions and full-image viewing. Nine dedicated case-study pages share the existing contact dialog and a darkened, full-width photo banner that fades between seven distinct projects. The brief and reference review are in [docs/REFERENCE-AUDIT.md](docs/REFERENCE-AUDIT.md).

Run `npm ci`, then `npm run dev`. Open http://127.0.0.1:3000. The navigation’s light/dark toggle remembers the selection between visits. The first-visit logo intro runs once per browser session; a new tab or cleared session storage replays it.

Run `npm run typecheck`, `npm test`, and `npm run build` for code checks. With the development server running, `npm run verify` checks desktop/mobile layouts, reduced motion, keyboard interactions, and form behavior in headless Chrome. `node scripts/verify-projects.mjs` checks all nine project routes, accordion playback, full-image viewing, contact access, skip navigation, and the scroll ribbon. `node scripts/verify-theme.mjs` checks persisted themes, responsive headers, service autoplay, and clicking moving ribbon projects. `node scripts/verify-photo-polish.mjs` checks all 47 curated popup photos, panel fill during transitions, the mobile hero spacing, and the fading case-study banners. `node scripts/verify-hero.mjs` checks the intro and photo joins through a full carousel cycle at desktop, Retina, and mobile dimensions. Screenshots and reports are saved in `qa/`. Set `CHROME_PATH` if Chrome is installed somewhere other than the standard macOS location.

Copy `.env.example` to `.env.local` and supply a Resend API key and verified sender to enable form delivery. Until those are configured, the form preserves the message and offers a prefilled email to Nick. Browser verification intercepts delivery responses and does not send real messages. Keep preview indexing disabled until launch; set `SITE_URL` to the final URL and review `app/layout.tsx` when publishing.

Photos and video excerpts are local under `public/media/`. The 65 project-gallery images have individual source records in [docs/project-gallery-sources.json](docs/project-gallery-sources.json); responsibility and story sources are in [docs/project-story-sources.json](docs/project-story-sources.json). Additional media and logos are indexed in [docs/media-sources.json](docs/media-sources.json). The original ZIP, deck, research downloads, and rejected concept work remain outside the application's public files.
